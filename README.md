# Credit-Card-Fraud-Detection

## project overview
This project aims to detect fraudlent credit card transactions using machine learning techniques using 
machine learning techniques.The dataset is highly imbalanced, making fraud detection a challenging classifciation problem.

## problem statement
Financial institutions lose millions due to fraudulent transactions. The objectiv is to build apredictive model that can
accurately identify fraudulent transactions while minimizing false poitives.

**important note :-
Scaling is applied on data already
